# **High level description**

The Public Cloud team regularly produces new Ubuntu images, sometimes at the cadence of one a day. When there are high profile vulnerabilities, our public cloud partners often want to know the first image in our stream that contains the vulnerability remediation.

My goal is work with AI agents to create tooling that will take a CVE as an input and returns the first image that contains a fix for that CVE. This will require the manifest files associated with each image and the CVE OVAL feeds generated by the Security team.

I plan to approach the task by first asking the AI agent to generate a spec.md file, and then after review and some revision iterations, I will ask the AI agent to generate code.

# **Claude Spec Request**

Create a spec.md that describes a tool that takes a CVE number as an input and returns the name of the first Ubuntu GCP image that contains a fix for that CVE. The manifest file containing the versioned package list for each 24.04 image is in the GCP bucket gs://ubuntu\_os\_cloud/ubuntu-noble-amd64-server-YYYMMDD.manifest. The 24.04 OVAL field is in [https://security-metadata.canonical.com/oval/com.ubuntu.noble.cve.oval.xml.bz2](https://security-metadata.canonical.com/oval/com.ubuntu.noble.cve.oval.xml.bz2) .  
Ask me if you need to clarify anything.
